# C. ML 기초 — "학습된다"는 것의 실체

## 왜 필요한가 (가장 중요한 영역)

VLM·DINOv2는 남이 만든 걸 갖다 쓴다. 하지만 **취향 학습기는 우리가 직접 만든다.**
온보딩 때 "A와 B 중 어느 사진이 좋아요?" 8~12쌍을 물어서 이 부부의 취향 벡터 w를
배우는 것. 이 작은 모델이 파이프라인에서 유일하게 우리가 "학습"시키는 부분이므로,
학습이 뭔지 실체를 알아야 한다.

---

## 1. 지도학습의 뼈대 — 입력 → 모델 → 손실 → 갱신

**비유 — 다트 연습.** 던진다(모델의 예측) → 과녁에서 얼마나 빗나갔나 본다(손실) →
그만큼 자세를 고친다(갱신) → 반복. "학습"은 마법이 아니라 **틀린 만큼 숫자를 조금씩
고치는 반복**이다.

```
입력 x  ──▶  모델(숫자 뭉치 w)  ──▶  예측  ──▶  정답과 비교 = 손실
                  ▲                                   │
                  └──── 손실이 줄어드는 방향으로 w를 조금 수정 ◀──┘
```

모델 = "숫자 뭉치 w로 입력을 출력으로 바꾸는 함수". 학습 = w를 고르는 것.

## 2. 로지스틱 회귀 — 취향 모델의 최소 구현체

가장 단순한 모델: **가중합 후 0~1로 짓눌러 확률로 만든다.**

```
점수  = w·x  (A에서 배운 내적 = 가중합)
확률  = σ(점수) = 1 / (1 + e^(−점수))
```

σ(시그모이드)는 어떤 숫자든 0~1 사이로 바꾸는 S자 함수다. 점수 0 → 0.5, 점수 +3 →
0.95, 점수 −3 → 0.05. 우리 취향 모델은 "사진 벡터 x를 넣으면 이 부부가 좋아할
확률"을 내는 로지스틱 회귀다. w의 각 숫자 = "x의 그 축을 얼마나 좋아하는가".

**손계산.** 2차원 장난감. 사진 x = (밝기 0.8, 인물 크기 0.2), 취향 w = (2, −1).
점수 = 2×0.8 + (−1)×0.2 = 1.4. 확률 = 1/(1+e^(−1.4)) ≈ 0.80. 이 부부는 밝은 사진을
좋아하고(w₁ 양수) 인물이 큰 걸 살짝 싫어하니(w₂ 음수) 이 사진은 80%로 좋아할 것.

## 3. 쌍 비교 학습 (Bradley-Terry) — 온보딩 데이터의 형태

우리는 "이 사진 몇 점?"이 아니라 **"A vs B 중 어느 쪽?"** 을 묻는다. 절대 점수보다
비교가 사람에게 쉽고 일관되기 때문. 이 데이터로 w를 배우는 표준 방법이 Bradley-Terry.

핵심 아이디어는 딱 하나:

```
P(A를 B보다 고른다) = σ( 점수(A) − 점수(B) ) = σ( w·x_A − w·x_B ) = σ( w·(x_A − x_B) )
```

즉 **두 사진 벡터의 차이 `x_A − x_B` 를 입력으로 하는 로지스틱 회귀**다. 정답은
"A를 골랐다 = 1". 새로운 알고리즘이 아니라 2번 모델을 차이 벡터에 적용한 것뿐.

**손계산.** w = (2, −1). x_A = (0.8, 0.2), x_B = (0.3, 0.6).
차이 = (0.5, −0.4). 점수 차 = 2×0.5 + (−1)×(−0.4) = 1.4. P(A 선택) ≈ 0.80.
부부가 실제로 A를 골랐다면 예측이 맞았고 손실이 작다. B를 골랐다면 손실이 크고,
w는 "차이 벡터 방향의 반대"로 수정된다.

왜 절편(상수항)이 없나? A와 B를 바꿔 물으면 확률이 정확히 1−p 가 되어야 하는데,
절편이 있으면 "왼쪽 사진을 무조건 선호"하는 편향이 생기기 때문이다.

## 4. 과적합과 정규화(L2) — 12쌍으로 768차원을 배우는 무모함

**비유 — 시험 문제 암기.** 기출 12문제를 통째로 외우면 그 12문제는 100점, 새 문제는
0점. 이게 과적합. 우리 상황이 정확히 그렇다: 배워야 할 숫자(w)가 768개인데 증거는
12쌍. 방정식보다 미지수가 60배 많으니 **12쌍을 완벽히 설명하는 w가 무한히 많고**,
그중 대부분은 새 사진에 엉뚱한 답을 낸다.

**L2 정규화** = "w는 웬만하면 0 근처에 있어라"는 벌칙을 손실에 더하는 것.

```
손실 = (예측이 틀린 정도) + C × (w의 각 숫자 제곱의 합)
```

증거가 약한 축의 w는 벌칙 때문에 0에 머물고, 12쌍이 일관되게 가리키는 축만 살아남는다.
B에서 배운 "사전 믿음"과 같은 것이다 — **"취향은 평균적으로 특별하지 않다(w≈0)"는
사전분포**, 증거가 쌓이면 그것을 밀어낸다. λ와 L2는 같은 철학의 두 얼굴이다.

## 5. 학습/검증/테스트 분리 — 왜 홀드아웃 정확도가 주지표인가

암기했는지 이해했는지 구분하려면 **안 본 문제로 시험**을 봐야 한다.

- 학습 세트: w를 맞추는 데 쓴 쌍 (예: 12쌍 중 9쌍)
- 홀드아웃: w를 맞출 때 안 보여 준 쌍 (나머지 3쌍). 여기서 맞추면 진짜 취향을 배운 것

"홀드아웃 쌍 예측 정확도"가 우리 주지표인 이유: 학습 세트 정확도는 과적합이면
무조건 100%라 의미가 없고, 홀드아웃만이 "새 사진에도 통하는가"를 말해 주기 때문.
50%면 동전 던지기와 같다(쌍 비교라서 우연의 기준선이 50%). B의 표본 크기 감각이
여기서 다시 필요하다 — 3쌍 중 2쌍 맞춘 67%는 우연과 구분되지 않는다.

## 손계산 과제

1. w = (1, 1, −2), x_A = (1, 0, 0), x_B = (0, 0, 1). P(A 선택)은? (점수차 3 → 0.95)
   -  d = x_A − x_B = (1, 0, 0) − (0, 0, 1) = (1, 0, −1)
      z = w · d = 1×1 + 1×0 + (−2)×(−1) = 1 + 0 + 2 = 3
      P(A 선택) = σ(3) = 1 / (1 + e⁻³) = 0.95257

2. 위에서 부부가 B를 골랐다. w의 세 숫자는 각각 어느 방향으로 고쳐지는가?
   (차이 벡터 (1, 0, −1)의 반대 방향 → w₁ 감소, w₂ 그대로, w₃ 증가)
   - 손실을 w로 미분하면 다음과 같다.
      ∇L = (p − y) · d
      부부가 B를 골랐으므로 y = 0, 그리고 p = 0.95257이다.
      ∇L = (0.95257 − 0) × (1, 0, −1) = (0.95257, 0, −0.95257)
      
      갱신: w ← w − η·∇L    (∇L의 반대 방향)
      갱신 방향 = (−0.95257, 0, +0.95257)
      방향	이유
      w₁	감소	d₁ = +1, A만 가진 특성인데 선택받지 못함 → 선호도 하향
      w₂	그대로	d₂ = 0
      w₃	증가	d₃ = −1, B만 가진 특성인데 선택받음 → 혐오도 완화
      답: w₁ 감소, w₂ 불변, w₃ 증가. 제시된 답이 맞다.

      실제 수치로 확인하면 (학습률 η별)
      η=0.1 : w → ( 0.905, 1, −1.905)   P(A) 0.953 → 0.943
      η=0.5 : w → ( 0.524, 1, −1.524)   P(A) 0.953 → 0.886
      η=1.0 : w → ( 0.047, 1, −1.047)   P(A) 0.953 → 0.749
      
      한 번의 갱신으로 정답(P(A)가 0.5 아래)에 도달하지 않는다. 여러 쌍을 반복해서 봐야 한다.
      w₂가 안 변한 이유를 오해하면 안 된다
      "2번 특성은 취향과 무관해서"가 아니다. 갱신량이 d에 정비례하는데 d₂ = 0이었을 뿐이다. 두 사진이 그 축에서 값이 같으면 비교 정보가 없으므로 배울 것도 없다.
      
      이 성질에는 실무적 함의가 있다. d_j = 0인 축은 그 쌍에서 영원히 학습되지 않는다. 후보 사진 쌍을 고를 때 서로 비슷한 사진만 보여주면 대부분의 d_j가 0에 가까워지고, 12쌍을 다 써도 배우는 축이 몇 개 안 된다. 앞서 "12쌍으로는 768개 축을 못 배운다"고 한 것의 구체적 메커니즘이 이것이다.
      
3. 학습 세트 정확도 100%, 홀드아웃 정확도 50%인 모델을 한 단어로 뭐라 하나?
   해결책을 두 가지 말하라. (과적합. 정규화 강화 / 데이터 추가)
   - 홀드아웃 50%는 이진 분류에서 무작위 추측과 동일하므로, 이 모델은 새 데이터에 대해 정보량이 0이다.
      해결책 두 가지: 정규화 강화 / 데이터 추가. 교과서 답으로는 맞다.
      
      다만 정규화 강화에 조건이 붙는다
      앞서 실제로 측정한 결과를 다시 보면, 12쌍 / 768차원 구간에서 L2 강도를 8자릿수(C=1e6 → 0.01) 바꿔도 검증 정확도는 0.502 → 0.504로 움직이지 않았다.
      정규화는 "데이터가 충분한데 모델이 잡음까지 외운 경우"에 듣는다. 미지수가 데이터의 60배인 구간에서는 애초에 골라낼 정보가 없어서 듣지 않는다. 같은 실험에서 실제로 효과가 있었던 것은 다음 두 가지였다.
      
      조치	12쌍 기준 검증 정확도
      정규화만 강화 (768차원 유지)	0.502 → 0.504
      차원 축소 768 → 32	0.530 → 0.637
      차원 축소 768 → 11	0.530 → 0.708
      데이터 추가 12쌍 → 1000쌍	0.530 → 0.744
      
      따라서 이 문제 상황에 한정해 두 가지를 고르라면 차원 축소 / 데이터 추가가 실효적이다. 정규화 강화는 세 번째 순위이고, 차원을 줄인 뒤에 병행하면 의미가 생긴다.

## 자가 점검

- "학습"을 다트 비유 없이 한 문장으로.
   - 학습이란, 관측된 데이터에 대해 정의된 손실 함수의 값이 줄어드는 방향으로 파라미터를 반복해서 갱신하는 절차.
   구성 요소 세 가지만 확인하면 된다. 파라미터(무엇을 바꾸나 = w), 손실(무엇을 기준으로 판단하나 = 로그 손실), 갱신 규칙(어느 방향으로 바꾸나 = 손실의 기울기 반대).

- BT가 로지스틱 회귀와 같은 모델이라는 걸 식 한 줄로 보여라.
   - BT 모델은 각 대상 i 에 양수 강도 π_i를 부여하고 P(i ≻ j) = π_i / (π_i + π_j) 로 둔다. 여기서 π_i = e^{s_i} 로 재매개화하면 다음 한 줄이 나온다.
