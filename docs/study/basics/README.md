# basics — 수식 없이 시작하는 AI 기초 (A→E)

`01~05` 영역은 실습 코드와 통계가 바로 나와서, 처음이면 두 번째 스텝에서 막힌다.
이 폴더는 그 **앞에 놓는 층**이다. 목표는 딱 하나 — 우리 추천 점수식 한 줄을
**남에게 말로 설명할 수 있게** 되는 것.

```
추천 점수 = 사진학 prior + λ·취향 + 커버리지 + MMR
              │            │  │         │
              │            │  └ 쌍 비교/별점 학습 ← [C] ML 기초
              │            └ 증거량 함수 λ(n)   ← [B] 확률·통계
              │
              └ VLM 태깅 + 임베딩 ← [A] 선형대수 + [E] 표현학습
평가: 홀드아웃 쌍 예측·nDCG ← [D] 평가 방법론
```

## 순서 (의존성 순서다 — 건너뛰지 말 것)

| 순서 | 파일 | 한 줄 요약 | 시간 |
|---|---|---|---|
| A | `A-linear-algebra.md` | 사진을 숫자 목록으로 바꾸면 "비슷하다"를 계산할 수 있다 | 1.5h |
| B | `B-probability-stats.md` | 증거가 적을 때는 개인 추정치를 평균 쪽으로 당긴다 (λ의 출처) | 2h |
| C | `C-ml-basics.md` | "학습된다" = 틀린 만큼 숫자를 조금씩 고친다. 쌍 비교로 취향 벡터 w를 배운다 | 3h |
| D | `D-recsys-eval.md` | 분류가 아니라 순서 매기기. nDCG·MMR·콜드스타트 | 1.5h |
| E | `E-representation-vlm.md` | DINOv2·CLIP·VLM은 각각 무엇을 받아 무엇을 뱉는가 | 1h |

각 파일 구조는 같다: **왜 필요한가 → 비유로 설명 → 손으로 계산하는 예제 하나 →
우리 시스템의 어디인가 → 자가 점검 3문항 → 다음 단계(01~05 어느 스텝)**.

## 통과 기준

- A: 두 벡터의 코사인 유사도를 계산기로 구할 수 있다
- B: (α+s)/(α+β+n) 를 종이에 재현하고 "왜 n이 커지면 개인 쪽으로 가는지" 말할 수 있다
- C: "12쌍으로 768차원 w를 배우면 왜 과적합이고 L2가 어떻게 막는지" 말할 수 있다
- D: 순위 2개를 주면 어느 nDCG가 큰지 계산 없이 판단하고, 이유를 말할 수 있다
- E: 세 모델(DINOv2·CLIP·VLM)의 입력/출력을 표로 그릴 수 있다

통과하면 `study/README.md`의 "진입 순서 1단계"로 간다. `/study-quiz`는 이 폴더도
출제 근거로 쓸 수 있다 (`/study-quiz basics`).
