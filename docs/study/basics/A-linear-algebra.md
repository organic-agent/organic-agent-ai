# A. 선형대수 — 딱 3개만

## 왜 필요한가

컴퓨터는 사진을 "예쁘다"고 느끼지 못한다. 대신 사진을 **숫자 목록**으로 바꾼 뒤,
숫자끼리 비교한다. 이 숫자 목록이 **벡터**다. 우리 시스템에서 DINOv2가 사진 한 장을
768개 숫자로 바꾸고, 그 뒤의 모든 일(비슷한 사진 묶기, 취향 점수, MMR)은 이 숫자
목록 위에서 벌어진다. 필요한 연산은 세 개뿐이다.

---

## 1. 벡터와 차원

**비유 — 맛집 평가표.** 식당을 (매운맛, 짠맛, 단맛) 세 항목으로 1~10점 매기면
`김치찌개집 = (8, 6, 2)`, `케이크집 = (0, 2, 9)` 처럼 숫자 3개로 요약된다.
이 숫자 3개 묶음이 벡터이고, 항목이 3개니까 **3차원**이다.

DINOv2는 사진을 평가하는 항목을 768개 가지고 있다고 보면 된다. 단, 그 항목이
"매운맛"처럼 사람이 이름 붙인 것이 아니라 **모델이 스스로 만든 축**이라서 각 숫자
하나의 뜻은 알 수 없다. 알 수 있는 건 "벡터 전체가 비슷하면 사진도 비슷하다"뿐이다.

> "DINOv2가 사진을 768차원 벡터로 바꾼다" = 사진 한 장을 768개 숫자로 요약한다.

## 2. 내적과 코사인 유사도 — "비슷하다"의 계산

두 식당이 비슷한지 어떻게 재나? 항목별로 곱해서 더한다. 이것이 **내적**.

```
김치찌개집 (8, 6, 2) · 된장찌개집 (7, 7, 1) = 8×7 + 6×7 + 2×1 = 56 + 42 + 2 = 100
김치찌개집 (8, 6, 2) · 케이크집   (0, 2, 9) = 8×0 + 6×2 + 2×9 =  0 + 12 + 18 = 30
```

비슷한 쪽이 크게 나온다. 그런데 내적은 **점수를 크게 매긴 식당**이 무조건 유리하다
(모든 항목이 10점인 식당은 누구와 내적해도 큼). 그래서 각 벡터의 "길이"로 나눠
크기 영향을 없앤 것이 **코사인 유사도**다. 값은 −1 ~ 1, 1이면 방향이 완전히 같음.

```
길이 = √(각 숫자 제곱의 합)
|김치찌개집| = √(64+36+4) = √104 ≈ 10.2
|된장찌개집| = √(49+49+1) = √99  ≈ 9.9
코사인 = 100 / (10.2 × 9.9) ≈ 0.99   ← 거의 같은 방향
|케이크집|   = √(0+4+81)  = √85  ≈ 9.2
코사인 = 30 / (10.2 × 9.2)  ≈ 0.32   ← 다른 방향
```

기하학적으로는 **두 화살표 사이의 각도**다. 각도가 0°면 1, 90°면 0, 반대면 −1.
"두 사진이 비슷하다" = "두 벡터의 각도가 작다".

**우리 시스템에서:** 중복 사진 클러스터링(코사인 0.95 이상이면 같은 컷으로 묶기),
MMR의 "이미 뽑은 것과 너무 비슷하면 감점" — 전부 이 연산 하나다.

## 3. 가중합 — 모든 "점수 계산"의 정체

여러 항목을 중요도(가중치)만큼 곱해서 더하는 것. 학점 계산이 가중합이다
(3학점 과목 A, 1학점 과목 B → 평점 = (3×A + 1×B) / 4).

우리 점수식의 핵심 부분:

```
최종 점수 = λ × 취향 점수 + (1 − λ) × 사진학 점수
```

λ=0.2면 취향 20%, 사진학 80%. λ=0.8이면 반대. **λ는 두 점수 사이의 믿음 배분**이고,
이걸 얼마로 둘지는 B(통계)에서 정한다.

그리고 사실 **내적 자체가 가중합**이다. C에서 배울 취향 벡터 w와 사진 벡터 x의
내적 `w·x = w₁x₁ + w₂x₂ + … + w₇₆₈x₇₆₈` 는 "사진의 각 특징에 취향 가중치를 곱해
더한 것" — 즉 취향 점수 = 가중합이다. 선형대수 3개가 사실 하나라는 게 여기서 보인다.

## 자가 점검

- 벡터가 768차원이라는 말을 비유 없이 한 문장으로 설명하면?
   - 사진 한장을 768 개의 실수로 이루어진 순서 있는 목록으로 표현한 것. 각 실수는 모델이 학습 과정에서 만든 튿징 축 하나에 대한 좌표값
   - 채점 기준이 되는 요소는 세가지 1. 차원 = 숫자의 개수. 2. 순서가 있음. 3. 각 칸의 의미는 사람이 정한 것이 아니라 학습으로 생겨난것.
   - 768 가지의 정보를 담고 있다 처럼 칸 하나가 사람이 해석 가능한 속성 하나에 대응한다고 말하는 것인데, 실제로는 개별 칸에 명시적 의미가 없고 벡터 전체의 위치, 방향의 의미를 갖는다.
- 내적 대신 코사인을 쓰는 이유는?
   - 내적은 방향과 크기가 곱해진 값이라 벡터가 길수록 유사도가 부풀려지는데, 코사인은 양쪽 크기로 나눠 크기 성분을 소거하고 방향의 일치도만 남기 때문. 
- λ=0.3일 때 취향 0.9, 사진학 0.5인 사진의 점수는? (0.62)
   - score = (1−λ)·prior + λ·pref
      = (1−0.3)·0.5 + 0.3·0.9
      = 0.7·0.5 + 0.3·0.9
      = 0.35 + 0.27
      = 0.62   ✓ 제시된 답과 일치
   - 여기서 확인해야할 감각은 계산 자체보다 결과의 방향. 취향 점수(0.9) 가 사진학 점수(0.5) 보다 훨씬 높은 사진인데도 최종 점수 0.62는 사진학 쪽(0.5) 에 더 가까움. λ=0.3 이라 취향의 발언권이 30% 뿐이기 때문. 증거가 적은 초반 라운드에서 "부부가 좋아할 법한 사진" 이 "교과석으로 잘 찍힌 사진" 을 이기기가 어려운 이유.
