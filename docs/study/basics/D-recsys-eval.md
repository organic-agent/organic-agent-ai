# D. 추천 시스템·평가 — 채택한 지표를 해석하는 능력

## 왜 필요한가

C까지 오면 "사진 한 장의 선호 확률"은 낼 수 있다. 그런데 우리가 내보내는 건 확률
하나가 아니라 **30장의 순서**다. 순서를 만드는 문제는 분류와 다르게 생겼고, 지표도
다르게 생겼다. 왜 nDCG인지, 왜 MMR이 붙는지를 알아야 실험 결과를 읽을 수 있다.

---

## 1. 랭킹 문제 — "좋은 사진인가"가 아니라 "어떤 순서로 보여줄까"

**분류**: 사진마다 좋다/나쁘다 판정. **랭킹**: 사진들을 줄 세우기.

**비유 — 식당 추천.** 친구에게 "이 식당 좋아?"(분류)와 "오늘 어디 갈까, 순서대로
5곳 말해줘"(랭킹)는 다른 질문이다. 랭킹에서는 1등이 틀리는 게 5등이 틀리는 것보다
훨씬 치명적이다. **위쪽 실수에 더 큰 벌을 주는 지표**가 필요하다.

우리 UI는 고객에게 30장을 위에서부터 보여 준다. 고객은 위 몇 장만 보고 판단한다.
그래서 랭킹 문제다.

## 2. nDCG — "위에 좋은 걸 놓을수록 점수가 크다"의 수식화

세 단계로 만들어진다.

**① 관련도(gain)**: 각 사진이 얼마나 좋은가. 별점을 쓰면 5점 사진은 gain 5, 1점은 1.

**② 위치 할인(discount)**: 아래로 갈수록 gain을 깎는다. 1등은 그대로, 2등은 ÷1.58,
3등은 ÷2, 4등은 ÷2.32… (수식은 log₂(위치+1)로 나누는 것 — 외울 필요 없고
"아래로 갈수록 완만하게 깎인다"만 기억).

**③ 정규화(n)**: 가능한 최고 순서(gain 큰 순)의 점수로 나눠 0~1로 맞춘다.
그래야 갤러리마다 사진 수·별점 분포가 달라도 비교된다.

**손계산.** 사진 3장, 참 관련도 A=3, B=2, C=1.

```
우리 순서 [B, A, C]:  DCG = 2/1 + 3/1.58 + 1/2 = 2 + 1.90 + 0.5 = 4.40
최선 순서 [A, B, C]: IDCG = 3/1 + 2/1.58 + 1/2 = 3 + 1.27 + 0.5 = 4.77
nDCG = 4.40 / 4.77 = 0.92

나쁜 순서 [C, B, A]:  DCG = 1 + 2/1.58 + 3/2 = 1 + 1.27 + 1.5 = 3.77 → nDCG 0.79
```

1등과 2등을 바꾼 것(0.92)보다 1등을 꼴찌로 보낸 것(0.79)이 훨씬 아프다. 이게
"위쪽 실수에 큰 벌"이다.

**계산 없이 판단하는 연습**: 두 순서가 있을 때 "제일 좋은 사진이 더 위에 있는 쪽"이
거의 항상 nDCG가 크다.

## 3. 콜드 스타트 — 증거 0개 문제의 업계 이름

새 부부가 들어왔다. 별점도 쌍 비교도 없다. 취향 모델은 아무것도 모른다. 이 상태가
콜드 스타트이고, 일반 추천 서비스에서는 예외지만 **우리는 모든 고객이 콜드 스타트로
시작**한다(갤러리마다 사진이 완전히 다르니까 남의 데이터도 못 빌린다).

우리의 답 두 가지:
- B의 λ(0) = 0 → 사진학 prior로만 추천. "아무것도 모를 땐 일반론".
- 온보딩 8~12쌍을 **먼저** 받아 증거 0을 피한다. λ_min은 이 온보딩 결과를 최소한
  반영하기 위한 바닥값.

## 4. MMR — 점수 순으로만 뽑으면 비슷한 사진 30장이 나간다

**문제.** 취향 점수 상위 30장을 뽑으면? 부부가 역광 실루엣을 좋아한다면 역광 실루엣이
30장 나온다. 점수는 다 높은데 **고객은 화가 난다** — 앨범엔 입장·행진·부모님 컷도
있어야 하니까.

**MMR(Maximal Marginal Relevance)** = 한 장씩 뽑되, 뽑을 때마다

```
뽑을 가치 = θ × 관련성(점수)  −  (1−θ) × 이미 뽑은 것과의 최대 유사도
```

A의 코사인 유사도가 여기 들어간다. 이미 역광 사진을 3장 뽑았으면 네 번째 역광
사진은 "유사도" 항 때문에 감점되고, 점수가 조금 낮아도 다른 장면의 사진이 올라온다.
θ가 두 번째 가중합 상수 — θ=1이면 순수 점수순, θ=0.5면 다양성 강하게.

우리 설계는 MMR 위에 **장면 커버리지**를 하나 더 얹는다: VLM 태그로 "입장·행진·
케이크컷·야외" 같은 장면이 최소 몇 장씩은 들어가도록. MMR은 "벡터가 비슷하면 감점",
커버리지는 "태그 기준으로 빠진 장면 보충" — 같은 목적을 두 층으로 지킨다.

## 5. 탐색-활용 — 재추천 루프에서 만날 개념

**비유 — 단골 식당 vs 새 식당.** 늘 가던 곳(활용)은 실패가 없지만 더 좋은 곳을
영영 못 찾는다. 가끔 새 곳(탐색)을 가야 취향이 넓어진다.

2차 셀렉에서 👍/👎를 받아 재추천할 때, 지금까지 좋아한 것만 더 보여 주면(활용만)
부부의 취향 중 우리가 아직 못 본 부분은 영원히 못 배운다. 30장 중 몇 장은 "확신은
낮지만 정보가 될 만한" 사진을 섞는 것이 탐색이다. 지금 설계엔 명시적 탐색 항은
없고, MMR의 다양성이 부분적으로 그 역할을 한다. 재추천 루프를 손볼 때 다시 온다.

   (앞: (3 + 0 + 3/2)/(3+3/1.58+0) = 4.5/4.9 = 0.92, 뒤: 1.0)

   0.2). MMR 값으로 어느 쪽을 다음에 뽑나? (X: 0.63−0.285=0.345, Y: 0.42−0.06=0.36 → Y)
   -

   (정확도=쌍 단위 취향 학습 품질, nDCG=최종 30장 순서 품질. 가능 — 취향은 잘
