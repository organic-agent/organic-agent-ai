# 02 ML/통계 기초 — 노트

자료 요약이 아니라 내 언어로 정리. 각 개념마다 "설계안의 어느 결정과 연결되는가"를 쓴다.
`/study-quiz 02`가 이 파일과 `materials.md` 체크 상태, `lab/` 코드를 출제 근거로 쓴다.

> **02의 성격** — 일반 통계 강의가 아니라 **01이 만든 숫자를 판정하는** 영역이다.
> 각 스텝이 01의 실습이 저지른 통계적 실수를 하나씩 잡는다. 상세는 `lab/README.md`.

## 개념 체크리스트 (실습과 짝지어져 있다)

### A. 구간과 커버리지 → `lab/step1_interval.py`
- [ ] 신뢰구간의 정의는 확률이 아니라 **커버리지** — "반복하면 95%가 참값을 포함"
- [ ] 그래서 통계 방법은 **세어서** 고를 수 있다 (시뮬레이션)
- [ ] Wald / Wilson / Clopper-Pearson의 차이와 각각이 맞는 자리
- [ ] 이산성의 톱니 — "n>30이면 정규근사"가 위험한 이유
- [ ] 쌍 풀링 구간은 좁은 게 아니라 **틀렸다**(커버리지 0.85). 추정 대상 정의의 중요성

### B. 편향-분산 → `lab/step2_bias_variance.py`
- [ ] 제곱오차 = 편향² + 분산. reg와 λ가 그 축 위의 손잡이
- [ ] **분산의 UX 번역** — 같은 고객이 온보딩을 다시 하면 추천이 얼마나 바뀌나
- [ ] 정확도가 부호만 보므로 **지표가 못 보는 변화**가 있다
- [ ] 학습 곡선 진단표 — 쌍을 더 받을지 피처를 바꿀지 정하는 법
- [ ] 임베딩은 고분산인데 **데이터로 못 고친다**(p≫n) → 표현 교체

### C. 경험적 베이즈와 shrinkage → `lab/step3_shrinkage.py`
- [ ] 야구 타율 = 우리 conf(axis). `(승+a)/(시도+a+b)`
- [ ] **conf가 학습 쌍에서 계산되어 낙관 편향** (승률 0.86 vs LOO 0.55)
- [ ] k는 임의 상수가 아니라 **(개인 내 잡음)/(사람 간 참값) 분산비**
- [ ] 신뢰도 곡선으로 k를 추정하는 법. 측정값 ≈ 114 (01의 가정은 10)
- [ ] shrinkage는 사전이 틀리면 날것보다 나쁘다 — 약한 사전이 안전한 이유

### D. 검증 설계 → `lab/step4_winners_curse.py`
- [ ] 승자의 저주 — 데이터를 늘려도 안 사라지는 이유
- [ ] 격자를 촘촘히 하면 검증 최댓값만 오르고 시험 성능은 내려간다
- [ ] train / validation / test의 역할과 "시험셋을 보면 검증셋이 된다"
- [ ] 사람 단위 분할이 필요한 이유 (쌍 단위는 누수)
- [ ] 중첩 교차검증 / 튜닝을 실험 밖으로 빼는 전략

### E. 다중 비교와 효과 크기 → `lab/step5_multiplicity.py`
- [ ] `1−(1−α)^m` 과 그것이 **독립 가정**이라는 것
- [ ] Bonferroni(FWER) vs BH(FDR) — 무엇을 통제할지 먼저 정한다
- [ ] 유의성은 표본 크기의 함수. 효과 크기(Cohen's h)와 MDE를 함께
- [ ] 08-25 VLM 채점 표에 적용하면 살아남는 결론이 무엇인가

### F. 리포트 → `lab/step6_report.py`
- [ ] 사전 등록서 여덟 줄과 각 줄의 출처
- [ ] 나쁜 리포트의 네 가지 잘못 — **계산이 아니라 절차**의 문제
- [ ] 정직해지면 구간이 넓어지고 주장이 줄어든다
- [ ] 한계를 스스로 적는 것의 의미
- [ ] 리포트의 마지막 줄은 "그래서 다음에 무엇을 하는가"

### G. 분류 지표와 임계값 → `lab/step7_classification.py`
- [ ] 희귀 사건에서 정확도가 무용한 이유 (기저율)
- [ ] 혼동행렬 네 칸 → 정밀도·재현율·F1
- [ ] **PR vs ROC** — 희귀 사건에서 ROC가 낙관적으로 보이는 이유(분모)
- [ ] 임계값은 비용비가 정한다. 기본값 0.5의 암묵적 가정
- [ ] **분류로 보이는 것이 순위 문제일 수 있다** (클러스터 대표 선정)
- [ ] 스파이크 관찰의 진단 — '점수가 낮다' vs '분산이 크다'

### H. 혼동행렬과 다중 클래스 → `lab/step8_confusion.py`
- [ ] 다중 클래스 정확도의 기준선 = 최빈 클래스 비율
- [ ] 같은 태거의 정확도가 갤러리 분포에 따라 바뀐다 (0.90 ↔ 0.76)
- [ ] 재현율 낮음 = 커버리지 실패 / 정밀도 낮음 = 이유 문장이 거짓
- [ ] micro vs macro — 커버리지가 있으면 macro
- [ ] 어휘 병합 판단을 상호 혼동 비중으로 하는 법
- [ ] **스칼라 오답률만 보면 안 보이는 오류가 있다** (오차 모델 버그)

### I. 확률 보정 → `lab/step9_calibration.py`
- [ ] 보정의 정의와 ECE. [0,1] 출력이 확률이 아닌 이유
- [ ] **보정과 순위는 독립** — Platt 후 AUC가 그대로인 것
- [ ] Platt vs isotonic, 그리고 isotonic이 AUC를 깎는 이유(ties)
- [ ] 백분위 변환 = 라벨 없는 순위 보정. 그 대가
- [ ] reg가 바꾸는 것은 정확도가 아니라 확신도
- [ ] 이유 문장마다 요구하는 근거의 종류가 다르다
