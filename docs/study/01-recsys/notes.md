# 01 추천 시스템 기초 — 노트

자료 요약이 아니라 내 언어로 정리. 각 개념마다 **"설계안의 어느 결정과 연결되는가"**를 쓴다.
`/study-quiz 01`이 이 파일과 `materials.md` 체크 상태, `lab/` 실행 이력을 출제 근거로 쓴다.

## 개념 체크리스트 (실습과 짝지어져 있다)

### A. Pairwise 선호 학습 → `lab/step1_bt.py`
- [ ] BT 선호 확률식 `P(i≻j)=π_i/(π_i+π_j)`와 `σ(β_i−β_j)` 변환
- [ ] contextual BT (`β_i = w·x_i`) = **차이 벡터에 대한 절편 없는 로지스틱 회귀**
- [ ] 왜 절편이 없는가 / 왜 부호 대칭 증강이 필요한가
- [ ] 아이템별 BT를 못 쓰는 이유 (갤러리마다 사진이 다름)
- [ ] 천장(ceiling) 개념 — 정답 w로도 100%가 안 나오는 이유

### B. 피처 설계와 정규화 → `lab/step2_features.py`
- [ ] p ≫ n 과적합, L2 정규화 = 가우시안 사전분포(MAP)
- [ ] 태그 원핫의 식별 문제 (축 내부 상대값만 의미)
- [ ] 온보딩 쌍 규칙(같은 scene·한 축만 다름·품질 근접)이 제거하는 교란변수
- [ ] 그 규칙의 대가: scene 취향은 원리적으로 학습 불가
- [ ] "온보딩 입력량"과 "실험 데이터량"이 다른 개념이라는 것

### C. 신뢰도 결합 → `lab/step3_lambda.py`
- [ ] λ = f(증거량) 곡선의 형태와 베이지안 사후평균과의 대응
- [ ] λ 상한을 두는 이유
- [ ] conf(axis) — 베타-이항 shrinkage, 50:50이면 0
- [ ] λ와 conf의 역할 분담 (전역 축소 vs 축 간 차등), z-표준화가 필요한 이유
- [ ] λ=1의 실패 모드 (한 축 쏠림 + 저품질 유입)
- [ ] 증거의 **질**(태그 정확도)도 λ를 움직인다 — 08-25 실측 오차 시 12쌍 최적 λ 0.4→0.2
- [ ] 쌍 규칙은 관측 태그로 판정되므로 태그 오차만큼 샌다 (풀의 33%)
- [ ] conf에 축 신뢰도를 곱해도 이득이 없는 이유 (기각된 가설)

### D. 다양성 재랭킹 → `lab/step4_mmr.py`
- [ ] MMR 식과 그리디 구현, λ_mmr의 의미
- [ ] MMR로 해결되는 실패 vs 커버리지로만 해결되는 실패
- [ ] 근접 중복 클러스터당 1장 규칙
- [ ] ILS·장면 종류·클러스터 중복을 함께 보는 이유 (단일 지표의 맹점)
- [ ] MMR(최댓값 벌점) ≠ ILS(평균) — ILS가 단조 감소하지 않는 이유
- [ ] 소프트 장치(MMR)와 하드 규칙(클러스터당 1장·커버리지)을 나누는 기준
- [ ] 실측 분포(snap 68%)에서 MMR 효과가 0이 되고 쿼터가 쏠림을 재생산하는 것

### E. 평가와 실험 설계 → `lab/step5_eval.py`
- [ ] 홀드아웃 쌍 정확도의 기준선 0.5, Wilson CI, 이항검정
- [ ] 검정력과 필요 표본 수 (차이의 제곱에 반비례)
- [ ] 군집 데이터 — 사람 단위 부트스트랩이 필요한 이유
- [ ] LOO 평가가 주는 것과 주지 않는 것
- [ ] nDCG / 수락률 / 후회율이 각각 잡아내는 실패
- [ ] 검정력 0.03의 실무적 의미 — 결과와 무관하게 결론을 못 낸다
- [ ] 표본 단위가 '쌍'이 아니라 '사람'인 이유
- [ ] 태그 정확도 → 필요 표본 수 (증거의 질이 실험 예산을 정한다)
- [ ] W1–2 실험 설계 권고안(10명 × 120쌍)의 근거를 스스로 재현하기

### F. 전체 파이프라인 → `lab/step6_pipeline.py`
- [ ] 반응(수락/거부)을 쌍으로 바꿔 evidence에 넣는 방식
- [ ] 자연어 피드백 → `{axis, tag, delta}` 가드레일
- [ ] 시뮬레이션으로 주장할 수 있는 것과 없는 것의 경계
- [ ] 반응 쌍이 온보딩 쌍보다 정보가 적은 이유 (교란변수 통제가 없다)
- [ ] 수락률이 평평해도 루프가 작동할 수 있는 이유 (학습 개선 vs 풀 고갈)
- [ ] 라운드 품질 지표의 조건 — 풀 고갈에 영향받지 않을 것 (lift·라운드별 홀드아웃)
