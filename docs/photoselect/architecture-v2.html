피사체 zero-shot 검증 (갤러리 1)

분포 couple 392 · groom 184 · bride 162 · unknown 84. 확신 라벨 무작위 36장(각 12) → 36/36 정답. unknown 84장의 argmax는 couple 70 정답, bride/groom 14 중 9가 실은 커플(신랑 등만 보이는 컷) — margin 게이트가 애매한 것만 걸러낸다. 그래서 subjects_trusted=True. 다른 유형 갤러리(본식·야외)에서 재확인 대상.

③ 배치 B추천 — 채워진 값이 어떻게 30장이 되나

부부가 POST /photo-selection/recommendations → wes가 분석 DONE·미제출 확인 → ai_selection_jobs(PENDING, draft|refine) → 워커 v2/draft.py:run().

B1

입력 — photo_analysis N행, 임베딩 E, Evidence(photo_selection_items의 담은 사진, ai_recommendations.rejected_at), 이전 라운드 추천.

B2

목표 장수 게이트 — remaining = target − 담은 수(target = galleries.max_selectable_photo_count). 0 이하면 {done:true}. k = min(30, remaining).

B3

점수

prior(p) = 0.5·technical_pct + 0.5·aesthetic_pct score(p) = z(prior) # 갤러리 내 표준화 + 0.5·z(deficit[type(p)]) + 0.5·z(select_lift[type(p)]) # 담은 사진 ≥ 5 이고 subjects_trusted 일 때만
B4

후보 제외 — exclude = 담은 사진 ∪ 이전 라운드에 보여준 사진 ∪ 거절. 한 번 보여준 사진은 다시 안 나온다. 품질로 제거하는 단계는 없다(하드 필터 금지).

B5

리랭킹 (v2/rerank.py)

  1. 컨셉 쿼터 — 크기 ≥ 3인 그룹만 대상. 각 최소 1, 나머지 크기 비례, 한 그룹 ≤ 40%·k. 그룹이 k보다 많으면 큰 그룹부터 k개만. 외톨이 그룹(1~2장)은 쿼터 없이 점수로만 뽑힘 — 최하위 사진이 "다양성"으로 끼는 것을 막는다.
  2. 그룹 안에서 연사 클러스터당 1장(점수 최고). 라운드 전체에서 한 클러스터는 한 번만.
  3. MMR argmax 0.7·score − 0.3·max_cos(이미 뽑힌 것) 그리디.
  4. 남으면 전체 점수순 fill. 각 pick에 slot ∈ quota·diversity·fill.
B6

근거 재료 수집 → 문장 (다음 절) → ai_recommendations INSERT. score_breakdown에 score·prior_z·balance_z·백분위·sharpness_pct·cluster/concept·slot·alternatives(형제와 탈락 사유)·facts·primary_reason이 전부 들어가 재현 가능.

근거 문장 — "거짓은 구조적으로 불가"

재료는 두 층이다. 1층 — 잰 수치와 셈(아래 표). 숫자·순위·장수는 여기서만 나오고, 템플릿은 이것만으로 만든다. 2층 — 사진 자체(LLM 켤 때만). 조명·구도·시선·표정·색처럼 눈에 보이는 것은 모델이 사진을 직접 보고 말한다. 사람 이름·장소·상황처럼 사진에도 재료에도 없는 것은 어느 층에도 없으므로 말할 수 없다. 1층의 우선순위 순:

종류조건템플릿 (갤러리 1 실제 출력)
balance담은 사진에서 이 유형이 갤러리 비율보다 부족 (4단계)담으신 사진에 신부 단독 컷이 부족해요 (1장/8장), 이 컷으로 채워요
qualitytech 또는 aes 백분위 상위 15%. 형제가 있으면 연사 절을 덧붙임전체 중 인상 상위 1%·화질 상위 4%, 연사 5장 중 점수가 가장 높은 컷이에요
sibling같은 연사 클러스터에 후보 형제가 있음. 탈락 사유 = 선명도 1.25배 차 → "덜 선명함", tech 5pt → "화질이 떨어짐", aes 5pt → "인상이 약함", 아니면 "거의 같은 컷"연사 6장 중 초점이 가장 또렷한 컷이에요, 나머지는 인상이 약함 2 · 화질이 떨어짐 3
concept크기 ≥ 3 컨셉 그룹에서 점수 1위이 배경으로 찍은 37장 중 점수가 가장 높은 컷이에요
score위 넷 없음, prior_z > 1기술·미학 점수가 갤러리 평균보다 뚜렷이 높은 컷이에요
diversity위 전부 없음 — 점수 언급 금지앞서 고른 사진들과 배경·구도가 겹치지 않아 고른 컷이에요

LLM 단계 — 뽑힌 k장에만, 사진을 보고 쓴다
